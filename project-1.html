CoinConvert — криптовалютный конвертер

Учебный криптовалютный конвертер для тех, кто хочет быстро узнать текущий курс криптовалюты и рассчитать её стоимость в разных фиатных валютах: евро, долларах, рублях и других.

Смотреть сайт

Учебный проект. Не коммерческая работа.

Подключила API

Подключила Coinbase API через API Connector в Bubble — получаю актуальные курсы криптовалют и использую их для расчёта суммы конвертации. Пользователь выбирает криптовалюту и валюту из выпадающего списка, вводит сумму, и сразу видит результат по актуальному курсу, без перезагрузки страницы.

Настроила интерфейс

Настроила dropdown, input и workflow, использовала custom states для хранения и передачи данных между элементами интерфейса. Самой сложной частью было подключение и настройка API, обработка получаемых данных и корректная передача их в расчёты Bubble.
